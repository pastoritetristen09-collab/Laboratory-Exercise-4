# Tristen's Autumn Tower (Laboratory Exercise 4)

Flask portfolio with an autumn + Harry Potter theme.

    pip install -r requirements.txt
    python app.py
    # open http://127.0.0.1:5000

Pages: Home, Profile (editable, photo + code upload), Contact, Work (capitalize text, circle, triangle), Linked List, Stacks (push/pop/peek, undo, reverse string, number bases, infix to postfix), Fun.
Profile edits are saved in data/profile.json and uploads in static/uploads/.
Theme choices are saved in your browser (Theme button, top right).
